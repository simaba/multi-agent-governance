# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] — Foundation release

### Added

- Multi-agent governance framework for oversight, trust boundaries, escalation, and auditability.
- Reusable multi-agent system governance review template.
- Filled generic sample system governance review.
- Agent inventory structure for documenting roles, trust levels, autonomy levels, data access, and owners.
- Trust-boundary, human-oversight, failure-mode, logging, and release-decision sections.
- README guidance clarifying the relationship between this repo, `agent-orchestration`, `agent-eval`, and `agent-simulator`.

### Notes

This repository focuses on governance structure for multi-agent systems. It does not provide the orchestration pattern catalog, evaluation scorecards, or runnable simulator.

### Next

- Add a machine-readable governance review schema.
- Add trust-boundary diagram examples.
- Add more examples for medium-risk and high-risk multi-agent workflows.
