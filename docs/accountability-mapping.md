# Accountability Mapping

A multi-agent system needs explicit ownership beyond agent prompts.

## Required ownership layers

- design owner
- runtime owner
- escalation owner
- incident owner
- improvement owner

## Example mapping

| Area | Accountable role | Supporting roles |
|---|---|---|
| Workflow design | Product or system owner | Engineering, domain expert |
| Runtime monitoring | Operations owner | Engineering |
| Escalation decision | Supervisor owner | Product, operations |
| Incident response | Operations owner | Engineering, governance |
| Post-incident improvement | Product or system owner | Engineering, operations |

## Design principle
Agents may perform tasks, but humans remain accountable for system behavior, release decisions, and corrective actions.
